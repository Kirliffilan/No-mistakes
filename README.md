# No-Mistakes

Обучающая игра со словами и буквами, разработанная на Unity с использованием C#.

## Реализованные механики

- Генерация слов и букв на основе текстовых файлов
- Проверка правильности выбранных букв
- Механика загрязнения и очистки букв
- Системы здоровья, очков и таймера
- Постепенное увеличение сложности
- Анимации игровых объектов и взаимодействий
- Обучающий режим с пошаговыми сценариями
- Настройки громкости и сохранение пользовательских настроек
- Адаптивный интерфейс с поддержкой горизонтальной и вертикальной ориентации экрана
- Поддержка разных соотношений сторон экрана

## Технологии

- Unity
- C#
- Unity UI
- ScriptableObject
- Coroutines
- Animator
- PlayerPrefs

## Платформа

- Android (локальная сборка APK)

## Запуск проекта

1. Клонировать репозиторий.
2. Открыть проект в Unity.
3. Открыть основную игровую сцену.
4. Запустить игру через Unity Editor.

Версию Unity можно посмотреть в `ProjectSettings/ProjectVersion.txt`.

## О проекте

Обучающая игра, разработанная для библиотеки с целью помочь детям изучать русский язык в интерактивном формате.
